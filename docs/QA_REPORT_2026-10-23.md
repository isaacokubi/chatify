## Defects fixed

1. **M-Pesa charges:** Chatify commission is zero for new payment requests, business/storefront/invoice/school fee flows, merchant POS STK prompts and generated POS QR amounts. Legacy pending records are normalized before a new initiation; already initiated or settled transactions are not rewritten. Safaricom's ordinary tariff can still apply. Regression tests cover exact requested amount and zero platform fee.
2. **Sparks:** Added a server-backed 24-hour text Spark lifecycle and top strip. Viewing marks the Spark viewed without hiding or deleting it. Owners can delete their own Sparks. The dialog now avoids disposing its input during route animation, and `Home` caches the subscribed app state so listener removal is safe during widget teardown. Unit and widget regression tests cover duration, view persistence and cleanup.
3. **Admin dashboard:** Added active Spark metrics and explicit 0% Chatify M-Pesa commission display; pending legacy fee records are identified as legacy.
4. **Memories:** Added a visible delete control with confirmation and immediate list/count update.
5. **Business catalogue:** Removed the Enterprise page's plan/usage card, compacted product rows, and removed its unused usage request to give catalogue entries more visible space.
6. **Saved contacts:** List entries now show the contact name, registered M-Pesa phone and email, with clear fallbacks for absent fields.
7. Fixed the moderate transitive `ip-address` advisory through a lockfile-only compatible dependency update. The final production dependency audit reports zero vulnerabilities.
8. **School records:** Learner, attendance, academic, fee and confirmed-receipt lists use horizontally scrollable tables. Learners show admission number, class, learner and parent/guardian contact fields; staff/admin can edit or archive while history remains. Added a widget regression test and made the learner register pager request the selected page.
