# Development
1. Copy server/.env.example to server/.env.
2. Set MONGODB_URI to a MongoDB Atlas database and JWT_SECRET to a random secret.
3. Run npm install, npm test, npm run lint and npm start in server.
4. Run flutter pub get, flutter analyze and flutter test in mobile.
5. For Android emulator development the sample API URL is http://10.0.2.2:5000. For a physical device replace it with the computer's LAN address.
