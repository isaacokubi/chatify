# Chatify Requirements

Functional: authentication, profiles, user search, direct messaging, groups, reactions, replies, read state, search, typing, presence, Memory Cards, message expiration and provider architecture for media/notifications.

Non-functional: mobile-first usability, maintainable modular code, server-side authorization, validation, network resilience, automated tests, documentation and credential isolation.

Academic innovation: Memory Cards convert useful conversational information into structured records; expiration lets users define a message lifecycle instead of treating every message as permanent.
